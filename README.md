# SANAD

## Repository layout

| Path | Purpose |
|------|---------|
| `docs/source/` | Original source documents (UX case study, system analysis & design). Read-only reference. |
| `docs/blueprint/` | High-level product blueprint: scope, modules, user roles, feature map. |
| `docs/architecture/` | System architecture: components, services, data flow, diagrams. |
| `docs/database/` | Data model: ERD, table definitions, migrations plan. |
| `docs/api/` | API contracts (endpoints, request/response shapes, OpenAPI specs). |
| `docs/ux/` | UX flows, screens, wireframes, design notes. |
| `docs/security/` | Auth, permissions, threat model, data protection. |
| `docs/decisions/` | Architecture Decision Records (ADRs), one file per decision. |
| `backend/` | Backend application. |
| `frontend/` | Frontend application. |
| `infrastructure/` | Deployment, Docker, CI/CD, environment config. |
